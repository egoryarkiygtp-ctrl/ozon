# Ozona Native Android

Нативное Android-приложение на Kotlin для расчёта юнит-экономики Ozon.

## Возможности версии 0.2.0
- FBO и FBS;
- цена, себестоимость, габариты и вес;
- процент выкупа и налог;
- комиссия, логистика, последняя миля, обработка и возвраты;
- прибыль на заказ и на выкупленную единицу;
- маржинальность, рентабельность и цена безубыточности;
- экспорт CSV (открывается в Excel) и PDF;
- автоматическая сборка APK через GitHub Actions.

## Сборка в GitHub
После загрузки файлов в корень репозитория:
1. Откройте вкладку Actions.
2. Выберите Build Native Android APK.
3. Нажмите Run workflow.
4. После зелёной сборки скачайте артефакт `ozona-native-debug-apk`.
5. В архиве артефакта находится `app-debug.apk`.

## Важно
Стартовые тарифы в коде являются демонстрационными. Их необходимо сверить с действующей
редакцией тарифов Ozon до использования для реальных финансовых решений.

## Почему CSV вместо настоящего XLSX
CSV корректно открывается в Microsoft Excel и не требует тяжёлой сторонней библиотеки внутри APK.
Поддержка полноценного XLSX будет добавлена после стабилизации основной сборки.
